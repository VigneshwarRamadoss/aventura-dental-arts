# Aventura Dental Arts

Welcome to the digital home of Aventura Dental Arts. This repository contains the source code for a premium, world-class dental practice website, designed to reflect the quality, precision, and high-end aesthetic of modern slow dentistry.

## 🌟 Key Features

*   **Premium Aesthetic:** A tailored user interface featuring elegant typography, bespoke color palettes (including warm, muted gold accents), and smooth micro-animations.
*   **Immersive Journal:** An editorial-style, full-screen reading experience for dental and aesthetic articles.
*   **Patient Portal:** A streamlined, secure-feeling hub for patient resources, forms, and insurance guidelines.
*   **Responsive Architecture:** A fluid and flawless experience across mobile, tablet, and desktop devices.

## 🛠️ Technology Stack

*   **Frontend Framework:** React (TypeScript)
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS (with custom design system utilities)
*   **Icons:** Lucide React

## 🚀 Getting Started

Follow these instructions to set up the project locally for development and testing.

### Prerequisites

*   [Node.js](https://nodejs.org/) (v18 or higher recommended)
*   npm (comes with Node.js)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/VigneshwarRamadoss/aventura-dental-arts.git
    cd aventura-dental-arts
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Environment Variables (if applicable):**
    Create a `.env.local` file in the root directory if the app requires external API keys.
    ```bash
    # Example
    # VITE_API_KEY=your_api_key_here
    ```

4.  **Start the development server:**
    ```bash
    npm run dev
    ```

5.  Open your browser and navigate to the local host URL provided in the terminal (usually `http://localhost:5173`) to view the application.

## 📦 Building for Production

To create an optimized production build, run:
```bash
npm run build
```
This will generate a `dist` directory containing all the minified, production-ready static assets.
